# Ranobe Project — Бесконечное Спасение

## Что это

Перевод ранобэ "Infinite Save: I Cultivate Immortality Through Reincarnation" (Бесконечное Спасение: Путь к Бессмертию через Перерождения) с ranobes.net.

## Структура

```
data_infinite/
├── raw/           — Сырые JSON главы (английский)
├── translated/    — Переведённые JSON главы (русский)
└── epub/          — Собранные EPUB

prompts/
└── translator-elite.md  — Промпт для перевода (использовать его!)
```

## Как переводить

Используй скилл `ranobe-translation` — там полный пайплайн.

Кратко:
1. Прочитай промпт: `prompts/translator-elite.md`
2. Найди непереведённые главы (raw без пары в translated)
3. Переведи через Antigravity + Gemini Flash (или API)
4. Сохрани в translated/ в формате JSON:
   ```json
   {
     "title": "Глава N: Название | Бесконечное Спасение: Путь к Бессмертию через Перерождения",
     "text": "Переведённый текст..."
   }
   ```
5. Собери EPUB

## Формат файлов

- **Raw**: `{"title": "Chapter X: English Title", "text": "English text..."}`
- **Translated**: `{"title": "Глава X: Русское название | Бесконечное Спасение...", "text": "Русский текст..."}`
