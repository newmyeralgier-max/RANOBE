# Agent Instructions — Ranobe Project

## Язык
**ОБЯЗАТЕЛЬНО**: Все инструкции, документация, СОПы — на **русском языке**.

## 3-слойная архитектура (Antigravity)

**Слой 1: Директивы (Что делать)** — СОПы в `directives/`, Markdown
**Слой 2: Оркестрация (Решения)** — это ты. Читаешь директивы, вызываешь скрипты, обрабатываешь ошибки
**Слой 3: Исполнение (Делание)** — Python-скрипты в `execution/`, детерминированные и надёжные

## Принципы
1. **Сначала проверь инструменты** — перед написанием нового скрипта проверь `execution/`
2. **Самоотжиг (self-anneal)** — при ошибке: прочитай ошибку → исправь → протестируй → обнови директиву
3. **Обновляй директивы** — узнал об ограничении API, баге, лучшем подходе — запиши в директиву

## Что делает этот проект
Скачивает ранобэ (light novels) с сайтов → переводит на русский через LLM API → собирает в EPUB/TXT.

## Поддерживаемые сайты
- **ranobes.com** — русский сайт, curl работает, пагинация по 25 глав
- **ranobes.net** — английская версия, блокирует headless Chrome, curl ок
- **freewebnovel.com** — без авторизации, 607 глав Horror Game Developer
- **royalroad.com** — нужен парсер (TODO)
- **webnovel.com** — нужна авторизация (TODO)

## Ключевые файлы
- `execution/ranobes_dl.py` — парсер ranobes.com + переводчик
- `execution/ranobes_tool.py` — парсер ranobes.net + переводчик
- `chat-export.json` — полная история переписки с заказчиком (важно для понимания задумки)

## API
- Fireworks API (OpenAI-совместимый): ключ в .env, модель llama-v3p3-70b-instruct для перевода
- Перевод: промпт "Ты профессиональный переводчик художественной литературы"
