# Директива: Парсер FreeWebNovel.com

## Цель
Скачать главы ранобэ с freewebnovel.com (без авторизации, чистый HTML)

## Контекст
FreeWebNovel — зеркало WebNovel, без авторизации. 607 глав Horror Game Developer.
Подтверждено: curl работает, глава скачивается, ~6700 символов на главу.

## Структура URL
- Книга: `https://freewebnovel.com/novel/{book-slug}.html`
- Глава: `https://freewebnovel.com/novel/{book-slug}/{chapter-slug}.html`
- Список глав: доступен через AJAX или пагинацию на странице книги

## Шаги
1. Загрузить страницу книги → извлечь slug, название, метаданные
2. Получить список всех глав (найти AJAX-эндпоинт или парсить пагинацию)
3. Для каждой главы:
   - GET запрос с User-Agent
   - BeautifulSoup → найти div с текстом главы
   - Извлечь название и текст
4. Сохранить сырые данные

## Важно
- Задержка 2с между запросами
- Сохранять прогресс (какие главы скачаны)
- Проверить HTML-структуру перед написанием парсера
