# Директива: Пайплайн скачивания и перевода ранобэ

## Цель
Автоматизировать скачивание ранобэ с сайтов + перевод на русский + сборка в EPUB.

## Вход
- URL книги на поддерживаемом сайте
- Диапазон глав (опционально, по умолчанию все)
- Формат вывода: EPUB (по умолчанию) или TXT
- Целевой язык перевода: RU (по умолчанию)

## Выход
- EPUB/TXT файл в папке `output/`
- Лог скачивания и перевода

## Шаги

### 1. Определить сайт и книгу
- Распарсить URL → определить сайт (ranobes.com, ranobes.net, freewebnovel.com и т.д.)
- Загрузить страницу книги → извлечь метаданные (название, автор, жанры, обложка)
- Получить список глав (с пагинацией если нужно)

### 2. Скачать главы
- Для каждой главы в диапазоне:
  - GET запрос (через urllib/requests, НЕ Selenium)
  - Извлечь текст из HTML (BeautifulSoup)
  - Сохранить сырой текст в `data/raw/` (для резьюме при обрыве)
  - Задержка 1.5с между запросами (не DDOSим)

### 3. Перевести текст
- Разбить каждую главу на чанки ~4000 символов (не рвать предложения)
- Отправить каждый чанк через Fireworks API
  - Промпт: "Ты профессиональный переводчик художественной литературы. Переводи литературно, сохраняя стиль. Только перевод."
  - Модель: accounts/fireworks/models/llama-v3p3-70b-instruct
  - temperature: 0.3
- Сохранять переведённые главы в `data/translated/`
- При ошибке — сохранить оригинал с пометкой [ОШИБКА]

### 4. Собрать EPUB
- Использовать библиотеку ebooklib
- Метаданные: название, автор, язык (ru)
- Обложка если есть
- Каждая глава = отдельная глава в EPUB
- Оглавление
- Сохранить в `output/Название_книги.epub`

### 5. Резьюме
- Проверять `data/raw/` перед скачиванием — если главы уже есть, пропускать
- Аналогично для `data/translated/`
- Это позволяет продолжить после обрыва

## Граничные случаи
- Сайт блокирует запросы → добавить рандомную задержку, сменить User-Agent
- Глава разбита на подстраницы → скачать все подстраницы (ranobes: .splitnewsnavigation)
- Текст в #arrticle (опечатка на ranobes, не #article)
- Пустая глава → пропустить, записать в лог
- API перевода таймаутится → retry 3 раза с backoff
- EPUB слишком большой → разбить на тома по ~200 глав

## Известные проблемы
- ranobes.net блокирует headless Chrome — использовать только curl/urllib
- ranobes.com: главы в обратном порядке на сайте → реверсировать
- FreeWebNovel: пока нет парсера, нужно написать
